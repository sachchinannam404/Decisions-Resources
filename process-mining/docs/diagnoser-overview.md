# Diagnoser Overview

## Overview

The **Diagnoser** explores the relationships between attributes and their outcomes as well as the root-cause behind an attribute.

Focusing on causality, the Diagnoser aims to pinpoint the causes behind a particular effect within its two types.

Two windows are available within the Diagnoser:

- **Impact Analyzer (default):** Visualizes the impact between the selected attribute and the target outcome
- **Root-Cause Analyzer:** Visualizes the root-cause behind the select attribute.
