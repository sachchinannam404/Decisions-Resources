# Variant Explorer Overview

## Overview

After generating an event log of a process, the **Variant Explorer** may discover differences in process execution behavior to analyze their effects on performance.

Discovering variants within a process promotes standardization by finding the causes behind the variation which indicate potential process improvements to prevent similar variant occurrence in the future.

To view the Variant Explorer, open an event log and open a new tab by selecting the plus icon at the bottom of the screen. From there, select the Variant Explorer.

Two windows are available within the Variant Explorer:

- **Discover Variants (default)**: Allows users to automatically or manually uncover variants by using [**Variant Rules**](/process-mining/docs/discovering-variants-with-variant-rules)**.**
- [**Explore Variants**](/process-mining/docs/examining-variants): Allows users to investigate every found variant within an execution, its frequency, and its length.
